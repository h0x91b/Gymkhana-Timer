Rebuilt the WebGL variant of the app from scratch on top of the bench's GPU pipeline. webgl-app.html, app-webgl.js, and webgl-detector.js are now a clean rewrite — the UI is full-screen with a centred serif timer (sized via min(46vh, 22vw) so all six tabular-num glyphs fit on a vertical phone), a signal-coloured tint that switches between orange / red / green / parchment / ivory by phase, and a green reticle for ROI selection. The display pass now draws a clearly visible green outline around the active ROI (fwidth-driven thickness) so the rider can always see where the detector is looking. A threshold slider lives in the top bar and is wired straight to the detector. Last-ten-runs history is persisted to localStorage and rendered in the bottom-right corner with the best time highlighted. The debug overlay is on by default, two lines: motion + threshold + ratio/threshold ratio on top, FPS + Δt±jitter + state + reference status on the bottom. The detector exposes a minimal API (setRoi, setThreshold, captureReference, hasReference, process, drawDisplay, cooldownRemaining, lastMotionRatio, debugLine) and runs a single combined metrics shader pass that emits motion / drift / luma in one readPixels(1×1) per frame, with brightness compensation fed back from the previous frame. State machine drops the stillness measurement and the mid-run reference-refresh — OBSERVING just waits a fixed two seconds, captures the reference, and rolls into ARMED. Camera recovery and the Hard-refresh button were intentionally dropped per the rebuild brief; the bench remains untouched as the perf reference, and canvas-app.html is unaffected.
