Added `webgl-motion-test.html`, a standalone WebGL2 bench page that compares two consecutive camera frames inside a fixed 400×500 ROI and reports the motion ratio as a single readPixels(1×1). Each pipeline stage (texImage2D upload, diff draw, generateMipmap reduce, readPixels) is timed separately with performance.now(); when EXT_disjoint_timer_query_webgl2 is available the GPU-only time is also reported in milliseconds (nanosecond precision, asynchronous). Surfaces every unhandled error and promise rejection through both an on-page label and an alert so quirky devices (Xiaomi MIUI, Samsung Internet, etc.) cannot fail silently with a black screen. Adds a non-blocking log panel that records each lifecycle event (getUserMedia, loadedmetadata, loadeddata, playing, video.play resolution, first frame). Adds a Hard refresh button that wipes every SW cache, unregisters every service worker on the origin, and reloads with a cache-busting query — useful when the bench page is served stale from the main app's service worker. The page is not wired into the production app — it exists only to produce numbers for the detector.js redesign.
