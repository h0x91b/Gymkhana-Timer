Rewrote webgl-detector.js around a single combined metrics pass. The fragment shader now emits three independent measurements at once — R = motion mask, G = signed Δluma drift biased into 0..1, B = absolute current luma — so generateMipmap + one readPixels(1×1) returns motion ratio, mean brightness drift, and mean ROI luma in four bytes. Stillness vs the previous frame is gone: when a reference exists, "still" simply means "current frame is close to the reference" (motion ratio low), and that single number tells us whether the ROI is empty; when no reference exists yet (first OBSERVING in a session) observeStillness returns 0 so app.js's STABILITY_DURATION timer fires after the usual 2s and captures the first reference. Brightness compensation is wired through a uniform fed with the previous frame's drift, so a uniform exposure shift across the ROI is no longer counted as motion — fixing the long-standing canvas-side issue too. Removes _texPrev / _fboPrev / pixelDiffThreshold / FS_DIFF / _hasPrevFrame and replaces them with the single FS_METRICS pipeline; resetStillness becomes a no-op for API compatibility.
