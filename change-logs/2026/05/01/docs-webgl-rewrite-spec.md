Added TZ-webgl-rewrite.md — a self-contained spec for rebuilding the WebGL variant of the app from scratch on top of the webgl-bench.html pipeline instead of continuing to patch app-webgl.js + webgl-detector.js. Captures the UI must-haves (huge centred timer + signal-coloured background as the only non-negotiable elements), the simplified state machine without frame-to-frame stillness or adaptive mid-run reference refresh, the GPU pipeline copied from the bench, the ROI picker requirements (reuse pinch + reticle from canvas-app), and explicit non-goals for v1 (no service worker, no localStorage history, no i18n, no UI threshold slider). The next session starts by `cp webgl-bench.html webgl-app.html` and builds the state machine into the working bench shell rather than the other way around.
