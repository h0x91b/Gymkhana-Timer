Stripped the webgl detector down to a pure motion-vs-reference trigger. observeStillness now always returns 0 — app.js's STABILITY_DURATION timer fires after the usual 2 s and captures a fresh reference unconditionally. refreshReferenceSafely is a no-op so the reference stays frozen between OBSERVING transitions. No more frame-to-frame stillness diff, no adaptive mid-run refresh, no blend math; the only on-GPU work per frame is upload + ROI crop + metrics shader + mipmap reduce + readPixels(1×1). Brightness compensation in the metrics shader stays — it's safe and helps motion ratio stability against exposure shifts. Reference is recaptured each time the session loop re-enters OBSERVING, which is enough adaptation for outdoor light drift over a practice session.
