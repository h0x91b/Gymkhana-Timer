Gymkhana Timer

Hands-free start/finish-line timing for motorcycle gymkhana routes. Pick a build below.

Canvas timer The original detector — runs entirely in CPU on a 2D canvas. Stable on every device. Ceiling around 45 FPS on phones with a 60 FPS camera. WebGL timer New detector that does background subtraction on the GPU and reads back one pixel per frame. Targets a steady 60 FPS. Same hands-free lifecycle as the Canvas build. WebGL benchmark Standalone perf bench that measures each pipeline stage (texImage2D, diff draw, generateMipmap, readPixels) in milliseconds. Use it to verify a target device hits 60 FPS before relying on the WebGL build.
Same camera, same ROI, same timing rules. The detector implementation is the only thing that changes between Canvas and WebGL.
